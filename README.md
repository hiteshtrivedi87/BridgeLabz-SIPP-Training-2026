## 📝 Program Naming Convention

Use meaningful and descriptive file names.

### ✅ Good Examples

```java
EmployeeWageCalculator.java
PalindromeChecker.java
StudentManagementSystem.java
BankAccountDemo.java
```

### ❌ Avoid

```java
Program1.java
Test.java
Demo.java
NewFile.java
```

---

## 💬 Commit Message Guidelines

Use clear and meaningful commit messages.

### Examples

```bash
[Neeraj] Add: Control Flow assignments
[Neeraj] Refactor: Employee Wage Calculator
[Neeraj] Fix: Array index issue in payroll system
[Neeraj] Update: Weekly review document
```

### Avoid

```bash
update
done
changes
final
```
